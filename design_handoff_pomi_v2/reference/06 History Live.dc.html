Turn 12 · History
Every block, one card; open it to fix the record
A chronological list grouped by day. Each card carries what a block was: when it started, how much focus it earned, the four-pill segment bar showing which sessions were finished, and the tags it ran under. Tap a card to open the timeline — sessions, breaks, early stops, and each stretch between tag changes. Tap a stretch to retag it; the sheet has shortcuts for the whole session or block. Only whole blocks can be deleted — that's how you "start over". The confirm can be switched off. Each block keeps the session length and count it ran with, a block that runs past midnight stays on the day it started, and the block that's still running only lands here once it ends.

What's live
Filter glyph (top right) opens a sheet where any number of tags can be checked; a block shows if it carries any of them. The active filter reads as a dot trio + count under the header, with Clear.
Dev note · deleted tag in filter. Deleting a tag removes it from the active filter; if it was the only one, the filter clears and History shows everything. A one-line toast says why: “Filter cleared — tag deleted”.
Often used hides its heading when no tag has any logged time yet.
Cards open and close. The pill bar is the same segment bar as the timer: ochre finished, split for an early stop, track for never started.
Stretches (rows with a chevron) open the tag sheet. Past three tags a stretch reads "first tag +N" with a capped dot trio. Past three stretches a session shows two, then a "N more tag changes" row — session 3 of today's first block is deliberately hectic (25 changes) to show it.
Whole session / Whole block in the tag sheet is also the cleanup tool: it copies one stretch's tags across and collapses the mess into a single stretch.
Delete block is the only delete — sessions can't be removed on their own. It confirms first unless "Don't ask again" was ticked (reversible in Settings → Confirm before deleting).
Per-block setup. Wed's afternoon block ran at 50 m × 2 — two pills, and 50 m counts as finished. Settings changes never touch a block already started or logged.
Past midnight. Fri's late block ends at 1:00 the next morning ("+1") and stays filed under Friday.
Deleted tags leave their time as Untagged — nothing disappears from totals.
Time boundaries are shown but never editable — that's the scope line.
